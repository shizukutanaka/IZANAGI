IZANAGI Playground

The real izanagi_kit — the deterministic simulation kit from the IZANAGI workspace — compiled to WebAssembly and running entirely in this page. No server, no port, no reimplementation: the same integer-only code that ships as a Rust crate, driven by the seed you give it. Change the seed and the world changes; keep it and the result is bit-identical, on any machine. The dungeon sample prints its world hash so you can check that claim against a native run.

Samples mirror the kit's own terminal demos (noise_terrain_demo, wfc_demo, and the simulation half of kit_bridge). Built with ./build.sh from the playground-web/ crate — see its README for the frame format and design notes.
